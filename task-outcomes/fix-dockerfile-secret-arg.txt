## Message

Detected a secret passed via ARG or ENV in a Dockerfile. Docker images are built in layers; each RUN, COPY, and ADD instruction creates a new immutable layer. A secret injected via ARG or ENV is recorded in image metadata and layer history, recoverable by anyone who can pull the image via 'docker history' or layer extraction tools. Instead, use BuildKit secret mounts (RUN --mount=type=secret,...) so the secret is available only during that RUN step and never written to any layer.

   - The token is read securely at build time via `/run/secrets/QSE_TOKEN` and is never baked into image metadata or any layer.
